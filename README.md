# Gamehubativo

Aplicativo React com uma tela Android branca e sem conteúdo, preparado para gerar um projeto Android nativo e APK usando Capacitor.

## Instalação

```bash
pnpm install
```

## Executar no navegador

```bash
pnpm dev
```

## Preparar o Android

```bash
pnpm android:setup
```

## Gerar o APK

```bash
pnpm android:apk
```

Consulte [ANDROID.md](ANDROID.md) para os requisitos e detalhes do build nativo.
